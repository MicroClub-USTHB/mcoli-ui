# McCheckbox

The `McCheckbox` component provides an accessible checkbox input built on `@base-ui/react/checkbox` with polished MicroClub UI theming.

## Usage

```tsx
import { McCheckbox } from '@/components/ui/mc-checkbox'

export default function Example() {
  const [checked, setChecked] = React.useState(false)

  return (
    <McCheckbox
      checked={checked}
      onCheckedChange={setChecked}
      text="Accept terms"
      supportText="Required for submission"
    />
  )
}
```

## API Reference

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `checked` | `boolean`  `"indeterminate"` | `undefined` | Controlled checked state |
| `defaultChecked` | `boolean` | `undefined` | Initial checked state for uncontrolled usage |
| `onCheckedChange` | `(checked: boolean  "indeterminate") => void` | `undefined` | Callback when checked state changes |
| `disabled` | `boolean` | `false` | Disabled state |
| `id` | `string` | auto-generated | Input id for label association |
| `text` | `string` | `undefined` | Label text displayed next to checkbox |
| `supportText` | `string` | `undefined` | Secondary text displayed below label |
| `size` | `"sm"|"md"` | `"md"` | Checkbox size |
| `className` | `string` | `undefined` | Additional wrapper class names |

> All props from `@base-ui/react/checkbox` are supported and forwarded to `CheckboxPrimitive.Root`.
