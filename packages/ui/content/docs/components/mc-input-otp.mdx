## Overview

The `mc-input-otp` is a core component of the MicroClub UI library. Built on the **input-otp** primitive, it combines accessibility with MicroClub's signature styling via **Tailwind CSS v4**.

## Usage

```tsx
import {
  McInputOTP,
  McInputOTPGroup,
  McInputOTPSlot,
  McInputOTPSeparator,
} from "@/components/ui/mc-input-otp"

export default function Example() {
  return (
    <McInputOTP maxLength={6}>
      <McInputOTPGroup>
        <McInputOTPSlot index={0} />
        <McInputOTPSlot index={1} />
        <McInputOTPSlot index={2} />
      </McInputOTPGroup>
      <McInputOTPSeparator />
      <McInputOTPGroup>
        <McInputOTPSlot index={3} />
        <McInputOTPSlot index={4} />
        <McInputOTPSlot index={5} />
      </McInputOTPGroup>
    </McInputOTP>
  )
}
```

## API Reference

### McInputOTP

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `maxLength` | `number` | — | Total number of OTP characters |
| `value` | `string` | `undefined` | Controlled value |
| `onChange` | `(value: string) => void` | `undefined` | Callback when value changes |
| `disabled` | `boolean` | `false` | Disables the input |
| `containerClassName` | `string` | `undefined` | Classes for the outer container |
| `className` | `string` | `undefined` | Classes for the input element |

### McInputOTPSlot

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `index` | `number` | — | Slot index, must match its position in the OTP (required) |
| `invalid` | `boolean` | `false` | Applies error styling with a red border on hover |
| `className` | `string` | `undefined` | Additional CSS classes |

### McInputOTPGroup

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | `undefined` | Additional CSS classes |

### McInputOTPSeparator

Renders a `—` separator between groups. Accepts standard div props.
