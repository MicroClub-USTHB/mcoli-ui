## Overview

The `mc-badge` is a compact label used to highlight status, categories, or metadata.
It is built on **@base-ui/react** and styled with **Tailwind CSS v4**. The same file also exports `McBadgeGroup`, a pill that pairs a badge with a short message.

## Usage

```tsx

export default function Example() {
  return <McBadge>Label</McBadge>;
}
```


## Accessibility

- A badge has no role and is not focusable. Keep its label short and meaningful on its own.
- A badge with `iconOnly` has no text. Pass `aria-label` so screen readers can announce it.
- `McBadgeDot` is hidden from assistive technology. Do not use color alone to carry meaning, write the status in the label.
- To make a badge dismissible, put a real `<button>` with an `aria-label` in the `icon` slot.

## API Reference

### `McBadge`

Extends the Base UI `useRender` span props.

| Prop            | Type                                                                             | Default     | Description                                                     |
| --------------- | -------------------------------------------------------------------------------- | ----------- | --------------------------------------------------------------- |
| `variant`       | `"default" \| "primary" \| "secondary" \| "destructive" \| "outline" \| "ghost"` | `"default"` | Visual style. Inside `McBadgeGroup` the default is `"primary"`. |
| `size`          | `"sm" \| "md" \| "lg"`                                                           | `"sm"`      | Size of the badge. Inside `McBadgeGroup` the group sets it.     |
| `icon`          | `ReactNode`                                                                      | `undefined` | Icon to show. Use `McBadgeDot` for the dot.                     |
| `iconPosition`  | `"start" \| "end"`                                                               | `"start"`   | Side of the label where the icon sits.                          |
| `iconOnly`      | `boolean`                                                                        | `false`     | Hides the label and shows only `icon`. Add `aria-label`.        |
| `image`         | `string`                                                                         | `undefined` | URL of a flag or avatar image. Replaces `icon`.                 |
| `imageAlt`      | `string`                                                                         | `""`        | Alt text for `image`.                                           |
| `imagePosition` | `"start" \| "end"`                                                               | `"start"`   | Side of the label where the image sits.                         |
| `render`        | `ReactElement \| ((props: HTMLProps) => ReactElement)`                           | `undefined` | Polymorphic render prop from Base UI.                           |
| `className`     | `string`                                                                         | `undefined` | Additional CSS classes.                                         |

### `McBadgeGroup`

| Prop            | Type                                                   | Default     | Description                                          |
| --------------- | ------------------------------------------------------ | ----------- | ---------------------------------------------------- |
| `size`          | `"md" \| "lg"`                                         | `"md"`      | Size of the group and of the inner badge.            |
| `badgePosition` | `"leading" \| "trailing"`                              | `"leading"` | Whether the badge comes before or after the message. |
| `render`        | `ReactElement \| ((props: HTMLProps) => ReactElement)` | `undefined` | Polymorphic render prop from Base UI.                |
| `className`     | `string`                                               | `undefined` | Additional CSS classes.                              |

### `McBadgeGroupText`

| Prop        | Type        | Default     | Description                                        |
| ----------- | ----------- | ----------- | -------------------------------------------------- |
| `icon`      | `ReactNode` | `undefined` | Icon shown after the message, for a leading badge. |
| `className` | `string`    | `undefined` | Additional CSS classes.                            |

### `McBadgeDot`

An 8px dot that follows the text color. Pass it as the `icon` of `McBadge`.

### Other exports

`McBadgeVariants` and `McBadgeGroupVariants` are the `cva` style functions, for styling your own elements like a badge.
