## Overview

The `mc-breadcrumb` is a navigation component of the MicroClub UI library. It provides accessible, semantic breadcrumbs with composable building blocks and MicroClub styling via **Tailwind CSS v4**.

As a part of the MicroClub library, this component is designed for **instant deployment into your codebase**, giving you full ownership of its look and behavior.

## Usage

```tsx
import {
  Breadcrumb,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbList,
  BreadcrumbPage,
  BreadcrumbSeparator,
} from '@/components/ui/mc-breadcrumb';

export default function Example() {
  return (
    <Breadcrumb>
      <BreadcrumbList>
        <BreadcrumbItem>
          <BreadcrumbLink href="/">Home</BreadcrumbLink>
        </BreadcrumbItem>
        <BreadcrumbSeparator />
        <BreadcrumbItem>
          <BreadcrumbPage>Current Page</BreadcrumbPage>
        </BreadcrumbItem>
      </BreadcrumbList>
    </Breadcrumb>
  );
}
```

## Composition Guide

Use these building blocks together to create a complete breadcrumb.

| Element               | Role               | Typical Usage                                           |
| --------------------- | ------------------ | ------------------------------------------------------- |
| `Breadcrumb`          | Navigation wrapper | Root container for the whole breadcrumb                 |
| `BreadcrumbList`      | Ordered list       | Holds all breadcrumb items in sequence                  |
| `BreadcrumbItem`      | Single step        | Wraps one link, page label, or ellipsis                 |
| `BreadcrumbLink`      | Navigable step     | Use for previous or parent levels                       |
| `BreadcrumbPage`      | Current location   | Use for the active page (non-clickable)                 |
| `BreadcrumbSeparator` | Visual divider     | Separates each item (default chevron or custom content) |
| `BreadcrumbEllipsis`  | Collapsed steps    | Replace middle levels when the path is too long         |

## Examples

### Default

```tsx
<Breadcrumb>
  <BreadcrumbList>
    <BreadcrumbItem>
      <BreadcrumbLink href="/">Home</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbLink href="/components">Components</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbPage>Breadcrumb</BreadcrumbPage>
    </BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>
```

### With Ellipsis

Use `BreadcrumbEllipsis` to collapse intermediate items in long paths.

```tsx
<Breadcrumb>
  <BreadcrumbList>
    <BreadcrumbItem>
      <BreadcrumbLink href="/">Home</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbEllipsis />
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbLink href="/components">Components</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbPage>Breadcrumb</BreadcrumbPage>
    </BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>
```

### Custom Separator

You can provide custom separator content through `BreadcrumbSeparator` children.

```tsx
<Breadcrumb>
  <BreadcrumbList>
    <BreadcrumbItem>
      <BreadcrumbLink href="/">Home</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator>/</BreadcrumbSeparator>
    <BreadcrumbItem>
      <BreadcrumbPage>Docs</BreadcrumbPage>
    </BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>
```

## API Reference

### Breadcrumb

| Prop        | Type                    | Default     | Description                 |
| ----------- | ----------------------- | ----------- | --------------------------- |
| `className` | `string`                | `undefined` | Additional CSS classes      |
| `...props`  | `ComponentProps<'nav'>` | `-`         | Native `<nav />` attributes |

### BreadcrumbList

| Prop        | Type                   | Default     | Description                |
| ----------- | ---------------------- | ----------- | -------------------------- |
| `className` | `string`               | `undefined` | Additional CSS classes     |
| `...props`  | `ComponentProps<'ol'>` | `-`         | Native `<ol />` attributes |

### BreadcrumbItem

| Prop        | Type                   | Default     | Description                |
| ----------- | ---------------------- | ----------- | -------------------------- |
| `className` | `string`               | `undefined` | Additional CSS classes     |
| `...props`  | `ComponentProps<'li'>` | `-`         | Native `<li />` attributes |

### BreadcrumbLink

| Prop        | Type                                        | Default     | Description                                |
| ----------- | ------------------------------------------- | ----------- | ------------------------------------------ |
| `className` | `string`                                    | `undefined` | Additional CSS classes                     |

| `...props`  | `useRender.ComponentProps<'a'>`             | `-`         | Native anchor props + Base UI render props |

| Prop        | Type                     | Default     | Description                  |
