## Overview

The `mc-breadcrumb` is a navigation component of the MicroClub UI library. It provides accessible, semantic breadcrumbs with composable building blocks and MicroClub styling via **Tailwind CSS v4**.

As a part of the MicroClub library, this component is designed for **instant deployment into your codebase**, giving you full ownership of its look and behavior.

## Usage

```tsx
import {
  McBreadcrumb,
  McBreadcrumbItem,
  McBreadcrumbLink,
  McBreadcrumbList,
  McBreadcrumbPage,
  McBreadcrumbSeparator,
} from '@/components/ui/mc-breadcrumb';

export default function Example() {
  return (
    <McBreadcrumb>
      <McBreadcrumbList>
        <McBreadcrumbItem>
          <McBreadcrumbLink href="/">Home</McBreadcrumbLink>
        </McBreadcrumbItem>
        <McBreadcrumbSeparator />
        <McBreadcrumbItem>
          <McBreadcrumbPage>Current Page</McBreadcrumbPage>
        </McBreadcrumbItem>
      </McBreadcrumbList>
    </McBreadcrumb>
  );
}
```

## Composition Guide

Use these building blocks together to create a complete breadcrumb.

| Element                 | Role               | Typical Usage                                           |
| ----------------------- | ------------------ | ------------------------------------------------------- |
| `McBreadcrumb`          | Navigation wrapper | Root container for the whole breadcrumb                 |
| `McBreadcrumbList`      | Ordered list       | Holds all breadcrumb items in sequence                  |
| `McBreadcrumbItem`      | Single step        | Wraps one link, page label, or ellipsis                 |
| `McBreadcrumbLink`      | Navigable step     | Use for previous or parent levels                       |
| `McBreadcrumbPage`      | Current location   | Use for the active page (non-clickable)                 |
| `McBreadcrumbSeparator` | Visual divider     | Separates each item (default chevron or custom content) |
| `McBreadcrumbEllipsis`  | Collapsed steps    | Replace middle levels when the path is too long         |

## Examples

### Default

```tsx
<McBreadcrumb>
  <McBreadcrumbList>
    <McBreadcrumbItem>
      <McBreadcrumbLink href="/">Home</McBreadcrumbLink>
    </McBreadcrumbItem>
    <McBreadcrumbSeparator />
    <McBreadcrumbItem>
      <McBreadcrumbLink href="/components">Components</McBreadcrumbLink>
    </McBreadcrumbItem>
    <McBreadcrumbSeparator />
    <McBreadcrumbItem>
      <McBreadcrumbPage>Breadcrumb</McBreadcrumbPage>
    </McBreadcrumbItem>
  </McBreadcrumbList>
</McBreadcrumb>
```

### With Ellipsis

Use `McBreadcrumbEllipsis` to collapse intermediate items in long paths.

```tsx
<McBreadcrumb>
  <McBreadcrumbList>
    <McBreadcrumbItem>
      <McBreadcrumbLink href="/">Home</McBreadcrumbLink>
    </McBreadcrumbItem>
    <McBreadcrumbSeparator />
    <McBreadcrumbItem>
      <McBreadcrumbEllipsis />
    </McBreadcrumbItem>
    <McBreadcrumbSeparator />
    <McBreadcrumbItem>
      <McBreadcrumbLink href="/components">Components</McBreadcrumbLink>
    </McBreadcrumbItem>
    <McBreadcrumbSeparator />
    <McBreadcrumbItem>
      <McBreadcrumbPage>Breadcrumb</McBreadcrumbPage>
    </McBreadcrumbItem>
  </McBreadcrumbList>
</McBreadcrumb>
```

### Custom Separator

You can provide custom separator content through `McBreadcrumbSeparator` children.

```tsx
<McBreadcrumb>
  <McBreadcrumbList>
    <McBreadcrumbItem>
      <McBreadcrumbLink href="/">Home</McBreadcrumbLink>
    </McBreadcrumbItem>
    <McBreadcrumbSeparator>/</McBreadcrumbSeparator>
    <McBreadcrumbItem>
      <McBreadcrumbPage>Docs</McBreadcrumbPage>
    </McBreadcrumbItem>
  </McBreadcrumbList>
</McBreadcrumb>
```
