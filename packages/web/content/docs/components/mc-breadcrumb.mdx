## Overview

The `mc-breadcrumb` is a navigation component of the MicroClub UI library. Built on semantic HTML elements, it provides accessible breadcrumbs with composable building blocks and MicroClub's signature styling via **Tailwind CSS v4**.

As a part of the MicroClub library, this component is designed for **instant deployment into your codebase**, giving you full ownership of its look and behavior.

## Usage

```tsx
import {
  McBreadcrumb,
  McBreadcrumbItem,
  McBreadcrumbLink,
  McBreadcrumbList,
  McBreadcrumbPage,
  McBreadcrumbSeparator,
} from '@/components/ui/mc-breadcrumb';

export default function Example() {
  return (
    <McBreadcrumb>
      <McBreadcrumbList>
        <McBreadcrumbItem>
          <McBreadcrumbLink href="/">Home</McBreadcrumbLink>
        </McBreadcrumbItem>
        <McBreadcrumbSeparator />
        <McBreadcrumbItem>
          <McBreadcrumbPage>Current Page</McBreadcrumbPage>
        </McBreadcrumbItem>
      </McBreadcrumbList>
    </McBreadcrumb>
  );
}
```

## Examples

### Default

```tsx
<McBreadcrumb>
  <McBreadcrumbList>
    <McBreadcrumbItem>
      <McBreadcrumbLink href="/">Home</McBreadcrumbLink>
    </McBreadcrumbItem>
    <McBreadcrumbSeparator />
    <McBreadcrumbItem>
      <McBreadcrumbLink href="/components">Components</McBreadcrumbLink>
    </McBreadcrumbItem>
    <McBreadcrumbSeparator />
    <McBreadcrumbItem>
      <McBreadcrumbPage>Breadcrumb</McBreadcrumbPage>
    </McBreadcrumbItem>
  </McBreadcrumbList>
</McBreadcrumb>
```

### With Ellipsis

Use `McBreadcrumbEllipsis` to collapse intermediate items in long paths.

```tsx
<McBreadcrumb>
  <McBreadcrumbList>
    <McBreadcrumbItem>
      <McBreadcrumbLink href="/">Home</McBreadcrumbLink>
    </McBreadcrumbItem>
    <McBreadcrumbSeparator />
    <McBreadcrumbItem>
      <McBreadcrumbEllipsis />
    </McBreadcrumbItem>
    <McBreadcrumbSeparator />
    <McBreadcrumbItem>
      <McBreadcrumbLink href="/components">Components</McBreadcrumbLink>
    </McBreadcrumbItem>
    <McBreadcrumbSeparator />
    <McBreadcrumbItem>
      <McBreadcrumbPage>Breadcrumb</McBreadcrumbPage>
    </McBreadcrumbItem>
  </McBreadcrumbList>
</McBreadcrumb>
```

### Custom Separator

You can provide custom separator content through `McBreadcrumbSeparator` children.

```tsx
<McBreadcrumb>
  <McBreadcrumbList>
    <McBreadcrumbItem>
      <McBreadcrumbLink href="/">Home</McBreadcrumbLink>
    </McBreadcrumbItem>
    <McBreadcrumbSeparator>/</McBreadcrumbSeparator>
    <McBreadcrumbItem>
      <McBreadcrumbPage>Docs</McBreadcrumbPage>
    </McBreadcrumbItem>
  </McBreadcrumbList>
</McBreadcrumb>
```

## API Reference

### Props

| Prop        | Type                    | Default     | Description                 |
| ----------- | ----------------------- | ----------- | --------------------------- |
| `className` | `string`                | `undefined` | Additional CSS classes      |
| `...props`  | `ComponentProps<'nav'>` | `-`         | Native `<nav />` attributes |

All props from the native `<nav />` element are supported.
