## Overview

The `mc-calendar` is a flexible date selection component for MicroClub UI. It is built on **react-day-picker** and styled with the design tokens and patterns used across the rest of the system.

For simple use cases, `McCalendar` gives you the full calendar UI. For form-style interactions, `McDatePicker` wraps the calendar in a popover trigger and provides a ready-made input-like experience.

## Usage

### Calendar

```tsx
import { useState } from 'react';
import { McCalendar } from '@/components/ui/mc-calendar';

export default function Example() {
  const [date, setDate] = useState<Date | undefined>(new Date());

  return <McCalendar mode="single" selected={date} onSelect={setDate} />;
}
```

### Date Picker

```tsx
import { useState } from 'react';
import { McDatePicker } from '@/components/ui/mc-calendar';

export default function Example() {
  const [date, setDate] = useState<Date | undefined>();

  return <McDatePicker label="Submission date" selected={date} onSelect={setDate} />;
}
```

## Examples

### Basic Calendar

```tsx
<McCalendar mode="single" selected={date} onSelect={setDate} />
```

### Date Picker

Use `McDatePicker` when you want a compact trigger that opens the calendar in a popover.

```tsx
<McDatePicker label="Submission date" selected={date} onSelect={setDate} />
```

### Date Range

```tsx
import type { DateRange } from 'react-day-picker';

const [range, setRange] = useState<DateRange | undefined>();

<McCalendar mode="range" selected={range} onSelect={setRange} />;
```

### Without Outside Days

```tsx
<McCalendar mode="single" showOutsideDays={false} selected={date} onSelect={setDate} />
```

### Disabled State

```tsx
<McCalendar mode="single" disabled selected={date} onSelect={setDate} />
```

## API Reference

### McCalendar Props

`McCalendar` accepts all props from `react-day-picker` `DayPicker`, plus a few MicroClub-specific options.

| Prop              | Type                                                             | Default      | Description                                                                      |
| ----------------- | ---------------------------------------------------------------- | ------------ | -------------------------------------------------------------------------------- |
| `showOutsideDays` | `boolean`                                                        | `true`       | Show days from adjacent months                                                   |
| `captionLayout`   | `"label" \| "dropdown" \| "dropdown-months" \| "dropdown-years"` | `"dropdown"` | Controls the month/year caption layout                                           |
| `buttonVariant`   | `McButton` variant                                               | `undefined`  | Variant used for the previous and next nav buttons. Unset renders plain chevrons |
| `className`       | `string`                                                         | `undefined`  | Additional CSS classes                                                           |

All other props from `react-day-picker` are supported.

### McDatePicker Props

`McDatePicker` is a convenience wrapper around `McCalendar` and a popover trigger.

| Prop               | Type                    | Default           | Description                               |
| ------------------ | ----------------------- | ----------------- | ----------------------------------------- |
| `label`            | `ReactNode`             | `undefined`       | Label shown above the trigger             |
| `placeholder`      | `ReactNode`             | `"Pick a date"`   | Text shown when no date is selected       |
| `dateFormat`       | `string`                | `"MMMM dd, yyyy"` | date-fns format for the selected date     |
| `id`               | `string`                | auto-generated    | Id of the trigger button                  |
| `selected`         | `Date`                  | `undefined`       | Currently selected date                   |
| `onSelect`         | `(date?: Date) => void` | `undefined`       | Fired when a date is selected             |
| `triggerClassName` | `string`                | `undefined`       | Additional classes for the trigger button |
| `className`        | `string`                | `undefined`       | Additional classes for the wrapper        |

All remaining calendar props are forwarded to `McCalendar`.
