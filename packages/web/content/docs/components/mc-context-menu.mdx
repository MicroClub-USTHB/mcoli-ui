## Overview

The `mc-context-menu` is a context menu component for MicroClub UI. Built on the **@base-ui/react** context menu primitive, it provides accessible right-click and long-press interactions with MicroClub styling via **Tailwind CSS v4**.

As a part of the MicroClub library, this component is designed for **instant deployment into your codebase**, giving you full ownership of its look and behavior.

## Usage

```tsx
import {
  ContextMenu,
  ContextMenuContent,
  ContextMenuItem,
  ContextMenuTrigger,
} from '@/components/ui/mc-context-menu';

export default function Example() {
  return (
    <ContextMenu>
      <ContextMenuTrigger>Right click here</ContextMenuTrigger>
      <ContextMenuContent>
        <ContextMenuItem>Back</ContextMenuItem>
        <ContextMenuItem>Forward</ContextMenuItem>
        <ContextMenuItem>Reload</ContextMenuItem>
      </ContextMenuContent>
    </ContextMenu>
  );
}
```

## Examples

### With Groups and Labels

```tsx
<ContextMenu>
  <ContextMenuTrigger>Right click here</ContextMenuTrigger>
  <ContextMenuContent>
    <ContextMenuGroup>
      <ContextMenuLabel>Actions</ContextMenuLabel>
      <ContextMenuItem>Back</ContextMenuItem>
      <ContextMenuItem>Forward</ContextMenuItem>
      <ContextMenuItem disabled>Reload</ContextMenuItem>
    </ContextMenuGroup>
  </ContextMenuContent>
</ContextMenu>
```

### With Shortcuts

```tsx
<ContextMenuItem>
  Back
  <ContextMenuShortcut>Alt+Left</ContextMenuShortcut>
</ContextMenuItem>
```

### With Checkbox Items

```tsx
<ContextMenuCheckboxItem checked>Show bookmarks</ContextMenuCheckboxItem>
<ContextMenuCheckboxItem>Show full URLs</ContextMenuCheckboxItem>
```

### With Radio Items

```tsx
<ContextMenuGroup>
  <ContextMenuLabel inset>Density</ContextMenuLabel>
  <ContextMenuRadioGroup value="comfortable">
    <ContextMenuRadioItem value="compact">Compact</ContextMenuRadioItem>
    <ContextMenuRadioItem value="comfortable">Comfortable</ContextMenuRadioItem>
    <ContextMenuRadioItem value="spacious">Spacious</ContextMenuRadioItem>
  </ContextMenuRadioGroup>
</ContextMenuGroup>
```

### With Submenus

```tsx
<ContextMenuSub>
  <ContextMenuSubTrigger>More tools</ContextMenuSubTrigger>
  <ContextMenuSubContent>
    <ContextMenuItem>Save page as...</ContextMenuItem>
    <ContextMenuItem>Create shortcut...</ContextMenuItem>
    <ContextMenuItem>Inspect</ContextMenuItem>
  </ContextMenuSubContent>
</ContextMenuSub>
```

## API Reference

### ContextMenu

The root component that manages context menu state.

All props from `@base-ui/react/context-menu` `Root` are supported.

### ContextMenuTrigger

The element that opens the context menu on right-click or long press.

All props from `@base-ui/react/context-menu` `Trigger` are supported.

### ContextMenuContent

The floating menu panel.

| Prop          | Type                                     | Default     | Description                              |
| ------------- | ---------------------------------------- | ----------- | ---------------------------------------- |
| `side`        | `"top" \| "bottom" \| "left" \| "right"` | `"right"`   | Preferred side of the trigger to open on |
| `sideOffset`  | `number`                                 | `0`         | Distance in px from the trigger          |
| `align`       | `"start" \| "center" \| "end"`           | `"start"`   | Alignment along the trigger axis         |
| `alignOffset` | `number`                                 | `4`         | Offset in px along the alignment axis    |
| `className`   | `string`                                 | `undefined` | Additional CSS classes                   |

All other props from `@base-ui/react/context-menu` `Popup` are supported.

### ContextMenuItem

An actionable menu item.

| Prop        | Type                         | Default     | Description                     |
| ----------- | ---------------------------- | ----------- | ------------------------------- |
| `inset`     | `boolean`                    | `undefined` | Adds left padding for alignment |
| `variant`   | `"default" \| "destructive"` | `"default"` | Visual style for the item       |
| `className` | `string`                     | `undefined` | Additional CSS classes          |
| `disabled`  | `boolean`                    | `undefined` | Disables item interaction       |

All other props from `@base-ui/react/context-menu` `Item` are supported.

### ContextMenuLabel

A label for a menu group.

`ContextMenuLabel` must be used inside `ContextMenuGroup`.

| Prop        | Type      | Default     | Description                     |
| ----------- | --------- | ----------- | ------------------------------- |
| `inset`     | `boolean` | `undefined` | Adds left padding for alignment |
| `className` | `string`  | `undefined` | Additional CSS classes          |

### ContextMenuGroup

Groups related menu items and labels.

All props from `@base-ui/react/context-menu` `Group` are supported.

### ContextMenuCheckboxItem

A checkable menu item.

| Prop        | Type      | Default     | Description            |
| ----------- | --------- | ----------- | ---------------------- |
| `checked`   | `boolean` | `undefined` | Checked state          |
| `inset`     | `boolean` | `undefined` | Adds alignment padding |
| `className` | `string`  | `undefined` | Additional CSS classes |

### ContextMenuRadioGroup

Groups mutually exclusive radio menu items.

All props from `@base-ui/react/context-menu` `RadioGroup` are supported.

### ContextMenuRadioItem

A selectable radio item inside `ContextMenuRadioGroup`.

| Prop        | Type      | Default     | Description            |
| ----------- | --------- | ----------- | ---------------------- |
| `value`     | `string`  | Required    | Radio item value       |
| `inset`     | `boolean` | `undefined` | Adds alignment padding |
| `className` | `string`  | `undefined` | Additional CSS classes |

### ContextMenuSub

The root component for a nested submenu.

All props from `@base-ui/react/context-menu` `SubmenuRoot` are supported.

### ContextMenuSubTrigger

The item that opens a nested submenu.

| Prop        | Type      | Default     | Description                     |
| ----------- | --------- | ----------- | ------------------------------- |
| `inset`     | `boolean` | `undefined` | Adds left padding for alignment |
| `className` | `string`  | `undefined` | Additional CSS classes          |

### ContextMenuSubContent

The floating panel for a submenu.

All props from `ContextMenuContent` are supported.

### ContextMenuSeparator

A visual separator between menu sections.

All props from `@base-ui/react/context-menu` `Separator` are supported.

### ContextMenuShortcut

Displays shortcut text aligned to the end of a menu item.

All props from `span` are supported.
