## Overview

The `mc-dialog` component is a modal surface built on top of **@base-ui/react/dialog** with
Micro Club UI styling.

It provides a composable API with dedicated slots for trigger, content, header, description,
footer, and close actions, while keeping accessibility and keyboard interactions handled by Base UI.

## Usage

```tsx
import { McButton } from '@/components/ui/mc-button';
import {
  McDialog,
  McDialogClose,
  McDialogContent,
  McDialogDescription,
  McDialogFooter,
  McDialogHeader,
  McDialogTitle,
  McDialogTrigger,
} from '@/components/ui/mc-dialog';

export default function Example() {
  return (
    <McDialog>
      <McDialogTrigger
        render={
          <McButton variant="primary" size="md">
            Open dialog
          </McButton>
        }
      />

      <McDialogContent>
        <McDialogHeader>
          <McDialogTitle>Edit profile</McDialogTitle>
          <McDialogDescription>
            Make changes to your profile here. Click save when you're done.
          </McDialogDescription>
        </McDialogHeader>

        <McDialogFooter showCloseButton={false}>
          <McDialogClose
            render={
              <McButton variant="secondary" size="md">
                Cancel
              </McButton>
            }
          />
          <McDialogClose
            render={
              <McButton variant="primary" size="md">
                Save changes
              </McButton>
            }
          />
        </McDialogFooter>
      </McDialogContent>
    </McDialog>
  );
}
```

## Examples

### Basic Dialog

```tsx
<McDialog>
  <McDialogTrigger render={<McButton>Open dialog</McButton>} />
  <McDialogContent>
    <McDialogHeader>
      <McDialogTitle>Title</McDialogTitle>
      <McDialogDescription>Description</McDialogDescription>
    </McDialogHeader>
  </McDialogContent>
</McDialog>
```

### Hide Top Close Button

```tsx
<McDialogContent showCloseButton={false}>
  <McDialogHeader>
    <McDialogTitle>Custom Header</McDialogTitle>
  </McDialogHeader>
</McDialogContent>
```

### Footer With Action Buttons

```tsx
<McDialogFooter showCloseButton={false}>
  <McDialogClose render={<McButton variant="secondary">Cancel</McButton>} />
  <McDialogClose render={<McButton variant="primary">Save changes</McButton>} />
</McDialogFooter>
```

## API Reference

### McDialog

| Prop       | Type                         | Default | Description                                 |
| ---------- | ---------------------------- | ------- | ------------------------------------------- |
| `...props` | `DialogPrimitive.Root.Props` | -       | All root props from `@base-ui/react/dialog` |

### McDialogTrigger

| Prop       | Type                            | Default | Description                      |
| ---------- | ------------------------------- | ------- | -------------------------------- |
| `...props` | `DialogPrimitive.Trigger.Props` | -       | Trigger element and interactions |

### McDialogContent

| Prop              | Type                          | Default     | Description                               |
| ----------------- | ----------------------------- | ----------- | ----------------------------------------- |
| `showCloseButton` | `boolean`                     | `true`      | Shows or hides the top-right close button |
| `className`       | `string`                      | `undefined` | Additional CSS classes                    |
| `...props`        | `DialogPrimitive.Popup.Props` | -           | All popup props from Base UI              |

### McDialogHeader

| Prop        | Type                          | Default     | Description            |
| ----------- | ----------------------------- | ----------- | ---------------------- |
| `className` | `string`                      | `undefined` | Additional CSS classes |
| `...props`  | `React.ComponentProps<'div'>` | -           | Native div props       |

### McDialogFooter

| Prop              | Type                          | Default     | Description                              |
| ----------------- | ----------------------------- | ----------- | ---------------------------------------- |
| `showCloseButton` | `boolean`                     | `false`     | Appends a default secondary close button |
| `className`       | `string`                      | `undefined` | Additional CSS classes                   |
| `...props`        | `React.ComponentProps<'div'>` | -           | Native div props                         |

### McDialogTitle

| Prop        | Type                          | Default     | Description                  |
| ----------- | ----------------------------- | ----------- | ---------------------------- |
| `className` | `string`                      | `undefined` | Additional CSS classes       |
| `...props`  | `DialogPrimitive.Title.Props` | -           | All title props from Base UI |

### McDialogDescription

| Prop        | Type                                | Default     | Description                        |
| ----------- | ----------------------------------- | ----------- | ---------------------------------- |
| `className` | `string`                            | `undefined` | Additional CSS classes             |
| `...props`  | `DialogPrimitive.Description.Props` | -           | All description props from Base UI |

### McDialogClose, McDialogOverlay, McDialogPortal

All these helpers forward their corresponding `@base-ui/react/dialog` primitive props directly.
