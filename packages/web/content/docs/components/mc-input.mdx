## Overview

The `mc-input` is a text input for the MicroClub UI library. Label, description, and error are built in as props — no separate Field wrapper needed. Four addon slots (start, end, top, bottom) accept any ReactNode for icons, text, buttons, or custom content. `McInputButton` is a companion component designed to fit inside addon slots.

As a part of the MicroClub library, this component is designed for **instant deployment into your codebase**, giving you full ownership of its look and behavior.

## Usage

```tsx
import { McInput } from '@/components/ui/mc-input';

export default function Example() {
  return <McInput label="Email" placeholder="olivia@example.com" />;
}
```

## Examples

### With Description

```tsx
<McInput
  label="Email"
  description="We'll never share your email."
  placeholder="olivia@example.com"
/>
```

### Error State

The `error` prop controls both the visual state and the message. When present, it replaces the description.

```tsx
<McInput
  label="Email"
  error="Please enter a valid email address."
  placeholder="olivia@example.com"
/>
```

### Icon Addons

```tsx
import { Search, Mail } from 'lucide-react';

<McInput label="Search" addonStart={<Search />} placeholder="Search..." />
<McInput label="Email" addonStart={<Mail />} placeholder="olivia@example.com" />
```

### Text Addons

```tsx
<McInput label="Price" addonStart="$" addonEnd="USD" placeholder="0.00" type="number" />
<McInput label="Website" addonStart="https://" addonEnd=".com" placeholder="yoursite" />
```

### McInputButton

`McInputButton` is purpose-built for input addon slots. It has four variants:

- **ghost** — transparent, for icon toggles
- **outline** — bordered, for secondary actions
- **filled** — solid background, for primary actions
- **attached** — full-height, shares the input border, auto-detects start/end position

```tsx
import { McInput, McInputButton } from '@/components/ui/mc-input';
import { Search } from 'lucide-react';

<McInput
  label="Search"
  addonStart={<Search />}
  addonEnd={<McInputButton variant="attached">Search</McInputButton>}
  placeholder="Search anything..."
/>;
```

### Block Addons

Use `addonTop` and `addonBottom` for toolbars, counters, and status bars.

```tsx
<McInput
  label="Amount"
  addonTop={
    <div className="flex w-full items-center justify-between">
      <span className="text-xs font-medium">Balance: $1,234.56</span>
      <button className="text-xs font-medium text-primary hover:underline">Max</button>
    </div>
  }
  addonStart={<DollarSign />}
  placeholder="0.00"
  type="number"
/>
```

## API Reference

### McInput Props

| Prop          | Type        | Default     | Description                                                |
| ------------- | ----------- | ----------- | ---------------------------------------------------------- |
| `label`       | `ReactNode` | `undefined` | Label rendered above the input                             |
| `description` | `ReactNode` | `undefined` | Help text below the input. Hidden when `error` is present. |
| `error`       | `ReactNode` | `undefined` | Error message below the input. `true` = red border only.   |
| `addonStart`  | `ReactNode` | `undefined` | Inline-start addon (icons, text, dropdowns)                |
| `addonEnd`    | `ReactNode` | `undefined` | Inline-end addon (buttons, badges, spinners)               |
| `addonTop`    | `ReactNode` | `undefined` | Block-start addon (toolbar, controls above the input)      |
| `addonBottom` | `ReactNode` | `undefined` | Block-end addon (character count, status bar below)        |
| `disabled`    | `boolean`   | `false`     | Disables interactions and applies disabled styles          |
| `required`    | `boolean`   | `false`     | Marks the input as required                                |
| `className`   | `string`    | `undefined` | Additional CSS classes for the root element                |

All standard HTML input attributes are also supported.

### McInputButton Props

| Prop        | Type                                             | Default     | Description                                                |
| ----------- | ------------------------------------------------ | ----------- | ---------------------------------------------------------- |
| `variant`   | `"ghost" \| "outline" \| "filled" \| "attached"` | `"ghost"`   | Visual style. `attached` goes flush with the input border. |
| `className` | `string`                                         | `undefined` | Additional CSS classes                                     |

All standard HTML button attributes are also supported.
