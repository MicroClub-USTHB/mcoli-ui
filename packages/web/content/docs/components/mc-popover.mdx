## Overview

The `mc-popover` is a core component of the MicroClub UI library. Built on the **@base-ui/react** popover primitive, it combines world-class accessibility with MicroClub's signature styling via **Tailwind CSS v4**.

As a part of the MicroClub library, this component is designed for **instant deployment into your codebase**, giving you full ownership of its look and behavior.

## Usage

```tsx
import {
  Popover,
  PopoverTrigger,
  PopoverContent,
  PopoverHeader,
  PopoverTitle,
  PopoverDescription,
} from '@/components/ui/mc-popover';

export default function Example() {
  return (
    <Popover>
      <PopoverTrigger>Open</PopoverTrigger>
      <PopoverContent>
        <PopoverHeader>
          <PopoverTitle>Title</PopoverTitle>
          <PopoverDescription>Description goes here.</PopoverDescription>
        </PopoverHeader>
      </PopoverContent>
    </Popover>
  );
}
```

## API Reference

### Popover

The root component that manages open/close state.

| Prop           | Type                      | Default     | Description                            |
| -------------- | ------------------------- | ----------- | -------------------------------------- |
| `defaultOpen`  | `boolean`                 | `false`     | Initial open state (uncontrolled)      |
| `open`         | `boolean`                 | `undefined` | Controlled open state                  |
| `onOpenChange` | `(open: boolean) => void` | `undefined` | Callback fired when open state changes |

### PopoverTrigger

The element that toggles the popover. Renders a `<button>` by default.

All props from `@base-ui/react/popover` `Trigger` are supported.

### PopoverContent

The floating panel that appears when the popover is open.

| Prop          | Type                                     | Default     | Description                              |
| ------------- | ---------------------------------------- | ----------- | ---------------------------------------- |
| `side`        | `"top" \| "bottom" \| "left" \| "right"` | `"bottom"`  | Preferred side of the trigger to open on |
| `sideOffset`  | `number`                                 | `4`         | Distance in px from the trigger          |
| `align`       | `"start" \| "center" \| "end"`           | `"center"`  | Alignment along the trigger axis         |
| `alignOffset` | `number`                                 | `0`         | Offset in px along the alignment axis    |
| `className`   | `string`                                 | `undefined` | Additional CSS classes                   |

All other props from `@base-ui/react/popover` `Popup` are supported.

### PopoverHeader

A layout wrapper for the title and description.

| Prop        | Type     | Default     | Description            |
| ----------- | -------- | ----------- | ---------------------- |
| `className` | `string` | `undefined` | Additional CSS classes |

### PopoverTitle

The accessible title of the popover.

| Prop        | Type     | Default     | Description            |
| ----------- | -------- | ----------- | ---------------------- |
| `className` | `string` | `undefined` | Additional CSS classes |

### PopoverDescription

The accessible description of the popover.

| Prop        | Type     | Default     | Description            |
| ----------- | -------- | ----------- | ---------------------- |
| `className` | `string` | `undefined` | Additional CSS classes |
