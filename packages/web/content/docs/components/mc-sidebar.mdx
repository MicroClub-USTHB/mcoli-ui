## Overview

The `mc-sidebar` is a layout and navigation system for MicroClub UI. It provides a complete sidebar architecture with provider state, collapsible behavior, grouped menus, nested navigation, and a content inset area.

Built as part of the MicroClub library, this component is designed for **instant deployment into your codebase**, while keeping full control over styling, structure, and interactions.

## Usage

```tsx
import {
  SidebarProvider,
  McSidebar,
  McSidebarContent,
  McSidebarInset,
} from '@/components/ui/mc-sidebar';

export default function Example() {
  return (
    <SidebarProvider>
      <McSidebar>
        <McSidebarContent>{/* sidebar items */}</McSidebarContent>
      </McSidebar>
      <McSidebarInset>{/* page content */}</McSidebarInset>
    </SidebarProvider>
  );
}
```

## Examples

### Basic Layout

```tsx
<SidebarProvider defaultOpen>
  <McSidebar>
    <McSidebarHeader>{/* header items */}</McSidebarHeader>
    <McSidebarContent>{/* menu groups */}</McSidebarContent>
    <McSidebarFooter>{/* footer items */}</McSidebarFooter>
  </McSidebar>
  <McSidebarInset>{/* main content */}</McSidebarInset>
</SidebarProvider>
```

### Variants

```tsx
<McSidebar variant="sidebar" />
<McSidebar variant="floating" />
<McSidebar variant="inset" />
```

### Collapsible Modes

```tsx
<McSidebar collapsible="icon" />
<McSidebar collapsible="offcanvas" />
<McSidebar collapsible="none" />
```

### Controlled Open State

Manage sidebar visibility programmatically with `open` and `onOpenChange` on `SidebarProvider`.

```tsx
import { useState } from 'react';
import { SidebarProvider, McSidebar } from '@/components/ui/mc-sidebar';

export default function Example() {
  const [open, setOpen] = useState(true);

  return (
    <SidebarProvider open={open} onOpenChange={setOpen}>
      <McSidebar />
    </SidebarProvider>
  );
}
```

### Nested Navigation with Collapsible Items

```tsx
<McSidebarMenu>
  <McSidebarCollapsible label="Projects" tooltip="Projects">
    <McSidebarMenuSubItem>
      <McSidebarMenuSubButton href="#">Backlog</McSidebarMenuSubButton>
    </McSidebarMenuSubItem>
    <McSidebarMenuSubItem>
      <McSidebarMenuSubButton href="#">Sprints</McSidebarMenuSubButton>
    </McSidebarMenuSubItem>
  </McSidebarCollapsible>
</McSidebarMenu>
```

### Sidebar Menu Button Variants

The `McSidebarMenuButton` supports different visual variants for various use cases.

```tsx
<McSidebarMenuButton variant="default">Default Style</McSidebarMenuButton>

<McSidebarMenuButton variant="outline" className="mt-2">
  Outline Style
</McSidebarMenuButton>
```

### Sidebar Menu Button Sizes

Choose the appropriate size for your menu items.

```tsx
<McSidebarMenuButton size="sm">Small</McSidebarMenuButton>
<McSidebarMenuButton size="default">Default</McSidebarMenuButton>
<McSidebarMenuButton size="lg" className="mt-2">Large</McSidebarMenuButton>
```

### Active State

Use `isActive` prop to highlight the currently active menu item.

```tsx
<McSidebarMenuButton isActive>Active Item</McSidebarMenuButton>

<McSidebarMenuButton>Regular Item</McSidebarMenuButton>
```

### Sidebar Trigger

A button component to toggle the sidebar open/closed state.

```tsx
<McSidebarTrigger />
```

### Sidebar Rail

A thin rail component that provides an alternative way to toggle the sidebar.

```tsx
<McSidebarRail />
```

### Sidebar with Groups

Organize menu items using groups with labels.

```tsx
<McSidebarGroup>
  <McSidebarGroupLabel>Navigation</McSidebarGroupLabel>
  <McSidebarMenu>
    <McSidebarMenuItem>
      <McSidebarMenuButton>Dashboard</McSidebarMenuButton>
    </McSidebarMenuItem>
    <McSidebarMenuItem>
      <McSidebarMenuButton>Settings</McSidebarMenuButton>
    </McSidebarMenuItem>
  </McSidebarMenu>
</McSidebarGroup>
```

### Sidebar with Badges

Display badges or counts on menu items.

```tsx
<McSidebarMenuItem>
  <McSidebarMenuButton>Notifications</McSidebarMenuButton>
  <McSidebarMenuBadge>5</McSidebarMenuBadge>
</McSidebarMenuItem>
```

### Sidebar with Skeleton Loading

Show loading state while content is being fetched.

```tsx
<McSidebarMenuSkeleton showIcon />
<McSidebarMenuSkeleton />
```

## API Reference

### `SidebarProvider` Props

| Prop           | Type                      | Default     | Description                               |
| -------------- | ------------------------- | ----------- | ----------------------------------------- |
| `defaultOpen`  | `boolean`                 | `true`      | Initial open state for uncontrolled usage |
| `open`         | `boolean`                 | `undefined` | Controlled open state                     |
| `onOpenChange` | `(open: boolean) => void` | `undefined` | Callback fired when open state changes    |
| `className`    | `string`                  | `undefined` | Additional classes for sidebar wrapper    |
| `children`     | `React.ReactNode`         | `undefined` | Sidebar and inset content                 |

Also supports standard `div` props.

### `McSidebar` Props

| Prop          | Type                                 | Default     | Description                              |
| ------------- | ------------------------------------ | ----------- | ---------------------------------------- |
| `side`        | `"left" \| "right"`                  | `"left"`    | Sidebar side placement                   |
| `variant`     | `"sidebar" \| "floating" \| "inset"` | `"sidebar"` | Visual style variant                     |
| `collapsible` | `"offcanvas" \| "icon" \| "none"`    | `"icon"`    | Collapse behavior mode                   |
| `className`   | `string`                             | `undefined` | Additional classes for sidebar container |
| `children`    | `React.ReactNode`                    | `undefined` | Sidebar internal content                 |

Also supports standard `div` props.

### `McSidebarCollapsible` Props

| Prop               | Type                                          | Default     | Description                                   |
| ------------------ | --------------------------------------------- | ----------- | --------------------------------------------- |
| `label`            | `React.ReactNode`                             | required    | Label content displayed in the trigger        |
| `icon`             | `React.ComponentType<{ className?: string }>` | `undefined` | Optional icon displayed before the label      |
| `tooltip`          | `string`                                      | `undefined` | Tooltip label when sidebar is collapsed       |
| `defaultOpen`      | `boolean`                                     | `false`     | Initial open state for uncontrolled usage     |
| `open`             | `boolean`                                     | `undefined` | Controlled open state                         |
| `onOpenChange`     | `(open: boolean) => void`                     | `undefined` | Callback fired when collapsible state changes |
| `triggerClassName` | `string`                                      | `undefined` | Extra classes for the trigger button          |
| `contentClassName` | `string`                                      | `undefined` | Extra classes for nested content container    |
| `chevronClassName` | `string`                                      | `undefined` | Extra classes for chevron icon                |
| `children`         | `React.ReactNode`                             | `undefined` | Nested menu items rendered when expanded      |

Also supports standard `li` props (except `children` is managed by the component API).

### `useSidebar` Hook

A hook to access the sidebar context state and controls.

| Return Value    | Type                        | Description                 |
| --------------- | --------------------------- | --------------------------- |
| `state`         | `"expanded" \| "collapsed"` | Current sidebar state       |
| `open`          | `boolean`                   | Whether the sidebar is open |
| `setOpen`       | `(open: boolean) => void`   | Function to set open state  |
| `toggleSidebar` | `() => void`                | Function to toggle sidebar  |
