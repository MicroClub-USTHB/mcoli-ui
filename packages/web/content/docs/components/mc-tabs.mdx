## Overview

The `mc-tabs` collection is a flexible tab navigation primitive for MicroClub UI. Built on the **@base-ui/react** tabs primitive, it delivers accessible focus behavior and clean MicroClub styling through Tailwind CSS.

Use `mc-tabs` when you need a polished tabbed interface with horizontal or vertical layout options.

## Usage

```tsx
import { McTabs, McTabsList, McTabsTrigger } from '@/components/ui/mc-tabs';

export default function Example() {
  return (
    <McTabs defaultValue="tab1">
      <McTabsList>
        <McTabsTrigger value="tab1">Tab 1</McTabsTrigger>
        <McTabsTrigger value="tab2">Tab 2</McTabsTrigger>
        <McTabsTrigger value="tab3">Tab 3</McTabsTrigger>
      </McTabsList>
    </McTabs>
  );
}
```

## Examples

### Horizontal Tabs

```tsx
<McTabs defaultValue="tab1">

    <McTabsTrigger value="tab2">Tab 2</McTabsTrigger>
    <McTabsTrigger value="tab3">Tab 3</McTabsTrigger>

```

### Vertical Tabs

```tsx
<McTabs defaultValue="tab1">
  <McTabsList variant="vertical">
    <McTabsTrigger value="tab1">Tab 1</McTabsTrigger>
    <McTabsTrigger value="tab2">Tab 2</McTabsTrigger>
    <McTabsTrigger value="tab3">Tab 3</McTabsTrigger>
  </McTabsList>
</McTabs>
```

## API Reference

### Props

| Prop            | Type                         | Default        | Description                             |
| --------------- | ---------------------------- | -------------- | --------------------------------------- |
| `variant`       | `"horizontal" \| "vertical"` | `"horizontal"` | Layout for the tab list                 |
| `defaultValue`  | `string`                     | `undefined`    | Initial tab value for uncontrolled mode |
| `value`         | `string`                     | `undefined`    | Controlled selected tab value           |
| `onValueChange` | `(value: string) => void`    | `undefined`    | Callback when the active tab changes    |
| `className`     | `string`                     | `undefined`    | Additional CSS classes                  |

All other props from `@base-ui/react/tabs` are supported.
