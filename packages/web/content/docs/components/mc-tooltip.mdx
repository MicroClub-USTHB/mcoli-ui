## Overview

The `mc-tooltip` is a core component of the MicroClub UI library. Built on the **@base-ui/react** tooltip primitive, it combines world-class accessibility with MicroClub's signature styling via **Tailwind CSS v4**.

As a part of the MicroClub library, this component is designed for **instant deployment into your codebase**, giving you full ownership of its look and behavior.

## Usage

```tsx
import {
  Tooltip,
  TooltipTrigger,
  TooltipContent,
  TooltipProvider,
} from '@/components/ui/mc-tooltip';

export default function Example() {
  return (
    <TooltipProvider>
      <Tooltip>
        <TooltipTrigger>
          <button>Hover me</button>
        </TooltipTrigger>
        <TooltipContent title="Tooltip Title" desc="This is a description." />
      </Tooltip>
    </TooltipProvider>
  );
}
```

## Examples

### Basic Tooltip

```tsx
<TooltipProvider>
  <Tooltip>
    <TooltipTrigger>
      <button className="px-4 py-2 bg-blue-500 text-white rounded">Hover me</button>
    </TooltipTrigger>
    <TooltipContent title="Hello" desc="This is a basic tooltip." />
  </Tooltip>
</TooltipProvider>
```

### Positioning

```tsx
<TooltipProvider>
  <Tooltip>
    <TooltipTrigger>
      <button className="px-4 py-2 bg-green-500 text-white rounded">Top</button>
    </TooltipTrigger>
    <TooltipContent side="top" title="Top Tooltip" />
  </Tooltip>
  <Tooltip>
    <TooltipTrigger>
      <button className="px-4 py-2 bg-red-500 text-white rounded">Bottom</button>
    </TooltipTrigger>
    <TooltipContent side="bottom" title="Bottom Tooltip" />
  </Tooltip>
</TooltipProvider>
```

### With Custom Content

```tsx
<TooltipProvider>
  <Tooltip>
    <TooltipTrigger>
      <button className="px-4 py-2 bg-purple-500 text-white rounded">Custom</button>
    </TooltipTrigger>
    <TooltipContent>
      <div className="text-center">
        <p className="font-semibold">Custom Content</p>
        <p>You can put anything here!</p>
      </div>
    </TooltipContent>
  </Tooltip>
</TooltipProvider>
```

## API Reference

### TooltipProvider Props

| Prop    | Type     | Default | Description                        |
| ------- | -------- | ------- | ---------------------------------- |
| `delay` | `number` | `0`     | Delay in ms before showing tooltip |

All other props from `@base-ui/react/tooltip/provider` are supported.

### Tooltip Props

All props from `@base-ui/react/tooltip/root` are supported.

### TooltipTrigger Props

All props from `@base-ui/react/tooltip/trigger` are supported.

### TooltipContent Props

| Prop          | Type                                     | Default     | Description                                     |
| ------------- | ---------------------------------------- | ----------- | ----------------------------------------------- |
| `className`   | `string`                                 | `undefined` | Additional CSS classes                          |
| `side`        | `"top" \| "bottom" \| "left" \| "right"` | `"top"`     | The side of the trigger to position the tooltip |
| `sideOffset`  | `number`                                 | `4`         | The offset from the trigger                     |
| `align`       | `"start" \| "center" \| "end"`           | `"center"`  | The alignment of the tooltip                    |
| `alignOffset` | `number`                                 | `0`         | The offset for alignment                        |
| `title`       | `string`                                 | `undefined` | The title text of the tooltip                   |
| `desc`        | `string`                                 | `undefined` | The description text of the tooltip             |
| `children`    | `ReactNode`                              | `undefined` | Custom content for the tooltip                  |

All other props from `@base-ui/react/tooltip/popup` and `@base-ui/react/tooltip/positioner` are supported.
