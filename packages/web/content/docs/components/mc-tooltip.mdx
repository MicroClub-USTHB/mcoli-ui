## Overview

The `mc-tooltip` is a core component of MicroClub UI. Built on the **@base-ui/react** tooltip primitive, it combines world-class accessibility with MicroClub's signature styling via **Tailwind CSS v4**.

As a part of MicroClub UI, this component is designed for **instant deployment into your codebase**, giving you full ownership of its look and behavior.

## Usage

```tsx
import {
  McTooltip,
  McTooltipTrigger,
  McTooltipContent,
  McTooltipProvider,
} from '@/components/ui/mc-tooltip';

export default function Example() {
  return (
    <McTooltipProvider>
      <McTooltip>
        <McTooltipTrigger>Hover me</McTooltipTrigger>
        <McTooltipContent title="Tooltip title" description="This is a description." />
      </McTooltip>
    </McTooltipProvider>
  );
}
```

`McTooltipTrigger` renders a `<button>`. To use your own element, pass it through `render` instead of nesting it:

```tsx
<McTooltipTrigger render={<McButton variant="secondary">Hover me</McButton>} />
```

<Callout>
  Tooltip content isn't announced by screen readers. Give icon-only triggers an `aria-label`.
</Callout>

## Examples

### Positioning

```tsx
<McTooltip>
  <McTooltipTrigger>Bottom</McTooltipTrigger>
  <McTooltipContent side="bottom" align="start" title="Bottom start" />
</McTooltip>
```

### Without Arrow

```tsx
<McTooltip>
  <McTooltipTrigger>Hover me</McTooltipTrigger>
  <McTooltipContent arrow={false} title="Tooltip title" description="No arrow." />
</McTooltip>
```

### With Custom Content

Children render below the title and description.

```tsx
<McTooltip>
  <McTooltipTrigger>Custom</McTooltipTrigger>
  <McTooltipContent title="Shortcuts">
    <p>
      Press <kbd>⌘K</kbd> to search.
    </p>
  </McTooltipContent>
</McTooltip>
```

## API Reference

### McTooltipProvider Props

| Prop    | Type     | Default | Description                        |
| ------- | -------- | ------- | ---------------------------------- |
| `delay` | `number` | `0`     | Delay in ms before showing tooltip |

All other props from `@base-ui/react/tooltip/provider` are supported.

### McTooltip Props

All props from `@base-ui/react/tooltip/root` are supported.

### McTooltipTrigger Props

All props from `@base-ui/react/tooltip/trigger` are supported.

### McTooltipContent Props

| Prop          | Type                                     | Default     | Description                                     |
| ------------- | ---------------------------------------- | ----------- | ----------------------------------------------- |
| `className`   | `string`                                 | `undefined` | Additional CSS classes                          |
| `side`        | `"top" \| "bottom" \| "left" \| "right"` | `"top"`     | The side of the trigger to position the tooltip |
| `sideOffset`  | `number`                                 | `16`        | The offset from the trigger                     |
| `align`       | `"start" \| "center" \| "end"`           | `"center"`  | The alignment of the tooltip                    |
| `alignOffset` | `number`                                 | `0`         | The offset for alignment                        |
| `arrow`       | `boolean`                                | `true`      | Show the arrow pointing at the trigger          |
| `title`       | `ReactNode`                              | `undefined` | The title text of the tooltip                   |
| `description` | `ReactNode`                              | `undefined` | The description text of the tooltip             |
| `desc`        | `ReactNode`                              | `undefined` | Deprecated alias for `description`              |
| `children`    | `ReactNode`                              | `undefined` | Custom content for the tooltip                  |

All other props from `@base-ui/react/tooltip/popup` and `@base-ui/react/tooltip/positioner` are supported.
