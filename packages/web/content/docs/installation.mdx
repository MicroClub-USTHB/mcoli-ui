This guide walks you through setting up mcoli-ui in your project. Whether you're starting fresh or integrating with an existing codebase, we've got you covered.

## Prerequisites

Before installing mcoli-ui, ensure your project meets these requirements:

- **React 18+** in any framework supported by shadcn/ui (the examples use the Next.js App Router)
- **Tailwind CSS v4** installed and configured
- **TypeScript 5.7+** for full type safety
- **Node.js 20.17+** to run the CLI

## Step 1: Set Up shadcn/ui Base

mcoli-ui builds on the shadcn/ui foundation. If you don't have it yet:

- **New Projects**: Create with [shadcn/create](https://ui.shadcn.com/create)
- **Existing Projects**: Add via [official installation](https://ui.shadcn.com/docs/installation)

This establishes the core registry structure and configuration that mcoli-ui extends.

## Step 2: Initialize mcoli-ui

Run the initialization command to add an mcoli-ui theme to your project:

<Tabs items={['npm', 'pnpm', 'yarn', 'bun']}>
  <Tab value="npm">npx mcoli-ui@latest init</Tab>
  <Tab value="pnpm">pnpm dlx mcoli-ui@latest init</Tab>
  <Tab value="yarn">yarn dlx mcoli-ui@latest init</Tab>
  <Tab value="bun">bunx mcoli-ui@latest init</Tab>
</Tabs>

The init command will:

- Check that shadcn/ui is initialized (it looks for `components.json`)
- Ask you to pick a theme, unless you pass one (`init primary`)
- Add the theme's CSS variables and base styles to your global CSS through shadcn
- Install the theme fonts, DM Sans and Plus Jakarta Sans

### Choosing Your Theme

During initialization, select from our 5 signature themes:

| Theme         | Description                                         |
| ------------- | --------------------------------------------------- |
| **Primary**   | Deep blue, professional and modern                  |
| **Secondary** | Purple, creative and bold                           |
| **Game Dev**  | Pink with yellow accents, fun and energetic         |
| **Robotics**  | Electric blue with tighter corners, technical       |
| **IT**        | Green, clean and professional for tech applications |

Each theme comes with carefully crafted color ramps, semantic tokens, and component presets.

## Step 3: Add Your First Component

Once initialized, add components to your project:

<Tabs items={['npm', 'pnpm', 'yarn', 'bun']}>
  <Tab value="npm">npx mcoli-ui@latest add mc-button</Tab>
  <Tab value="pnpm">pnpm dlx mcoli-ui@latest add mc-button</Tab>
  <Tab value="yarn">yarn dlx mcoli-ui@latest add mc-button</Tab>
  <Tab value="bun">bunx mcoli-ui@latest add mc-button</Tab>
</Tabs>

This injects the component source directly into `components/ui`, giving you full ownership and customization power.
