## Overview

mcoli-ui ships with **5 signature themes** designed to give your project a distinct visual identity. Each theme is crafted with Micro Club DNA, combining professional aesthetics with a bold, modern edge.

All themes support both **light** and **dark** modes out of the box.

## Available Themes

| Theme         | Value       | Description                                         | Light Primary | Dark Primary |
| ------------- | ----------- | --------------------------------------------------- | ------------- | ------------ |
| **Primary**   | `primary`   | Deep blue, professional and modern                  | `#0006B1`     | `#D9DDFF`    |
| **Secondary** | `secondary` | Purple, creative and bold                           | `#6A0DAD`     | `#8B5CF6`    |
| **Game Dev**  | `game-dev`  | Pink with yellow accents, fun and energetic         | `#D04F99`     | `#FBE2A7`    |
| **Robotics**  | `robotics`  | Electric blue with tighter corners, technical       | `#001EFF`     | `#2563EF`    |
| **IT**        | `it`        | Green, clean and professional for tech applications | `#34D399`     | `#34D399`    |

## Add a Theme to Your Project

Deploy a theme directly to your project:

<Tabs items={['npm', 'pnpm', 'yarn', 'bun']}>
  <Tab value="npm">npx mcoli-ui@latest init</Tab>
  <Tab value="pnpm">pnpm dlx mcoli-ui@latest init</Tab>
  <Tab value="yarn">yarn dlx mcoli-ui@latest init</Tab>
  <Tab value="bun">bunx mcoli-ui@latest init</Tab>
</Tabs>

### Interactive Mode

Running `npx mcoli-ui@latest init` without arguments launches an interactive theme selector.

### Specify a Theme Directly

You can also specify a theme directly:

<Tabs items={['npm', 'pnpm', 'yarn', 'bun']}>
  <Tab value="npm">npx mcoli-ui@latest init primary</Tab>
  <Tab value="pnpm">pnpm dlx mcoli-ui@latest init primary</Tab>
  <Tab value="yarn">yarn dlx mcoli-ui@latest init primary</Tab>
  <Tab value="bun">bunx mcoli-ui@latest init primary</Tab>
</Tabs>

Available themes: `primary`, `secondary`, `game-dev`, `robotics`, `it`

### Manual Setup

If you prefer manual control:

<Steps>

<Step>Choose a theme</Step>

Pick one of `primary`, `secondary`, `game-dev`, `robotics` or `it`.

<Step>Add it with shadcn</Step>

Each theme is published as a shadcn registry item. This is the command `init` runs for you:

```bash
npx shadcn@latest add https://mcoli-ui.microclub.info/r/primary.json
```

<Step>Or copy the values yourself</Step>

The light and dark palettes are defined in the mcoli-ui repository under
[`packages/web/registry/themes`](https://github.com/MicroClub-USTHB/mcoli-ui/tree/main/packages/web/registry/themes)
(`primaryTheme.ts`, `secondaryTheme.ts`, `gameDevTheme.ts`, `roboticsTheme.ts`, `itTheme.ts`).
Define each color as a CSS variable for light and dark mode, then map it to a Tailwind color:

```css
@theme inline {
  --color-primary: var(--primary);
  --color-primary-foreground: var(--primary-foreground);
  /* ... one mapping per token */
}

:root {
  --primary: #0006b1;
  --primary-foreground: #ffffff;
}

.dark {
  --primary: #d9ddff;
  --primary-foreground: #000350;
}
```

</Steps>

## Theme Structure

Each theme follows this structure:

```ts
export const themeName = {
  // Border radius values (vary by theme)
  theme: {
    'radius-sm': '0.25rem',
    'radius-md': '0.375rem',
    'radius-lg': '0.5rem',
    'radius-xl': '0.75rem',
    'radius-2xl': '0.75rem',
  },
  // Light mode colors
  light: {
    background: '...',
    foreground: '...',
    primary: '...',
    'primary-foreground': '...',
    // ... more colors
  },
  // Dark mode colors
  dark: {
    background: '...',
    foreground: '...',
    primary: '...',
    'primary-foreground': '...',
    // ... more colors
  },
};
```

<Callout>
  Border radius values differ between themes. Robotics uses tighter radii (`0.125rem` for `sm` and
  `md`, `0.25rem` above), while Game Dev uses a larger `radius-2xl` (`1rem`).
</Callout>

## Using Colors in Components

In your Tailwind classes, use these tokens as follows:

```tsx
className = 'text-muted-foreground'; // Uses --muted-foreground
className = 'bg-primary'; // Uses --primary
className = 'border-border'; // Uses --border
className = 'text-destructive'; // Uses --destructive
```

All colors are available as `bg-`, `text-`, `border-`, and other Tailwind utilities.

## Switching Themes

mcoli-ui components use CSS variables tied to theme tokens. To switch themes, re-run the init command with your desired theme:

<Tabs items={['npm', 'pnpm', 'yarn', 'bun']}>
  <Tab value="npm">npx mcoli-ui@latest init secondary</Tab>
  <Tab value="pnpm">pnpm dlx mcoli-ui@latest init secondary</Tab>
  <Tab value="yarn">yarn dlx mcoli-ui@latest init secondary</Tab>
  <Tab value="bun">bunx mcoli-ui@latest init secondary</Tab>
</Tabs>

This replaces the theme's CSS variables in your global CSS with the new theme's values.

## Customizing Themes

For advanced customization, you can extend or override any theme:

```css
@theme inline {
  --color-primary: var(--primary);
  --radius-lg: 1rem;
}

:root {
  --primary: your-custom-color;
}

.dark {
  --primary: your-custom-color;
}
```

This gives you full control while maintaining consistency across your project.
